# 🗂️ FileOrganizer

— Smart File Sorting & Cleanup Tool (Python)
A lightweight, fast, and reliable Python-based file management tool that automatically organizes messy folders into clean, structured directories. FileOrganizer sorts files by type, extension, size, or custom rules — helping users keep their workspace tidy with a single command.

## 🚀 Project Overview
📦 Phase 1: Core Sorting Engine
Scan any folder and detect all files

Automatically group files by type (Images, Videos, Documents, Audio, Archives, etc.)

Create destination folders dynamically

Move files safely with conflict handling

🔍 Phase 2: Smart Rules & Filters
Sort by extension (e.g., .png, .mp3, .zip)

Sort by size (Small / Medium / Large)

Sort by creation or modified date

Skip system files or user‑defined exclusions

🧹 Phase 3: Cleanup & Utility Tools
Remove empty folders

Detect duplicate files

Batch rename files

Generate logs of all operations

## 🧠 Features
### ✅ Core Features
One‑click folder cleanup

Automatic folder creation

Safe file moving with overwrite protection

Works on Windows, macOS, and Linux

### 📁 Sorting Modes
By file type (Images, Videos, Docs, etc.)

By extension

By size

By date

Custom rule sets
